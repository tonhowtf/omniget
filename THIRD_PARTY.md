# Third-party data, code and designs

OmniGet is GPL-3.0. This file lists what it takes from other projects, under which license, and where it lives in this repository. It starts with **washmybelly**, the cleanup, uninstall, privacy and performance superpower. The engines OmniGet runs for downloads (yt-dlp, FFmpeg, gallery-dl, aria2, librqbit and others) are credited in the README under "Standing on open source".

Every embedded source keeps its license file and a `SOURCE.md` with the upstream commit in `src-tauri/omniget-core/data/washmybelly/<source>/`. Nothing listed as data is downloaded at run time: it is compiled into the app with `include_str!`. Converted files are regenerated by the scripts in `scripts/washmybelly/`, never edited by hand.

## washmybelly

### Embedded as data

- **privacy.sexy** by undergroundwires. License: **GNU AGPL-3.0**.
  - What: the `windows.yaml`, `macos.yaml` and `linux.yaml` collections of version 0.13.8 (commit `7b956f3d8c8b80bbb2b5d0f77912431bf98fdafb`), copied byte for byte. OmniGet compiles them in its own Rust code and runs each item through typed operations, reading its state from the system.
  - Where: `src-tauri/omniget-core/data/washmybelly/privacy-sexy/`. That folder stays AGPL-3.0; OmniGet combines with it under section 13 of both licenses.
  - Source code: upstream at https://github.com/undergroundwires/privacy.sexy, and the exact copy OmniGet uses at https://github.com/tonhowtf/omniget/tree/main/src-tauri/omniget-core/data/washmybelly/privacy-sexy. OmniGet's MCP server can serve privacy.sexy results to other programs over HTTP, so this link is also shown in the app's Privacy screen and returned by the `wmb_capabilities` and `wmb_privacy_catalog` tools, as section 13 of the AGPL asks.
- **BleachBit** CleanerML by Andrew Ziem and contributors. License: **GPL-3.0-or-later**.
  - What: 105 files of `cleaners/*.xml` (commit `a373ed853e27b745812c46a4ee214e9964f66a6e`), unmodified.
  - Where: `data/washmybelly/bleachbit/` (with `COPYING`).
- **Mole** by tw93. License: **GPL-3.0**.
  - What: the protection list (`protection.txt`, bundle and path patterns that no rule may remove) and macOS cleanup targets ported by hand into `clean/rules_macos.rs` (marked `source: "Mole"`). Commit `1b6ac63fe75b7ff2c05430742eacab5c78ef16cd`.
  - Where: `data/washmybelly/mole/`.
  - The name and logo "Mole" are trademarks of the Mole project and never appear in OmniGet's interface.
- **Kudu** by Advent Development Inc. License: **MIT**.
  - What: 209 Windows cleanup rules converted from `rules/win32/*.json` (commit `4e0002259b58e8ee41925611831e8f4085295ddd`); the Restart Manager idea of showing which app holds a file.
  - Where: `data/washmybelly/kudu/`.
- **PureMac** by the PureMac contributors. License: **MIT**.
  - What: macOS cleanup targets from its CLI catalog and scan engine, ported by hand into `clean/rules_macos.rs` (commit `64d4d7fe645048440959c250a38f6b7428a9d633`). The parts of PureMac derived from Pearcleaner are not used.

- **Win11Debloat** by Raphire. License: **MIT**.
  - What: `Config/Apps.json` (the Appx app list) and `Config/Features.json` (tweaks), converted; the 140 `.reg` files those tweaks use, copied byte for byte (commit `32024662f3c602442e7af82bbf52c89143b31aeb`).
  - Where: `data/washmybelly/win11debloat/` and `data/washmybelly/win11debloat-features/`.
- **winutil** by CT Tech Group LLC (Chris Titus Tech). License: **MIT**.
  - What: the Store ids of `config/appx.json`, a curated registry-only part of `config/tweaks.json`, and the power plan and update deferral functions re-expressed as typed operations (commit `ad81e0a7aff424932afff77504e7440e07e19a15`). No PowerShell from winutil is run.
  - Where: `data/washmybelly/winutil/`, `data/washmybelly/winutil-tweaks/` and `data/washmybelly/tweaks/ours.json`.
- **Sophia Script for Windows** by farag2. License: **MIT**.
  - What: the list of Appx packages that are never removed, and 10 tweaks extracted by hand from `Sophia.psm1` (commit `1b761b48e3f680b6669c37ad61d92518d583a44e`).
  - Where: `data/washmybelly/sophia/` and `data/washmybelly/sophia-tweaks/`.

### External tools OmniGet calls

These are not shipped with OmniGet.

- **PresentMon** by Intel Corporation. License: **MIT**. On Windows, version 2.6.0 is downloaded from its official GitHub release the first time you measure FPS, checked against a fixed SHA-256 (the download is refused on a mismatch), and its license is saved next to it.
- **MangoHud** by flightlessmango. License: **MIT**. On Linux, used for FPS capture when it is installed; OmniGet only writes a config for its own session.
- **GameMode** by Feral Interactive. License: **BSD-3-Clause**. On Linux, OmniGet talks to its daemon over D-Bus only.
- **power-profiles-daemon**, **TLP**, **auto-cpufreq** and **tuned** are only detected, so the power screen can say which one is in charge.

### What did not go in, and why

- **Pearcleaner**: Apache-2.0 with the Commons Clause, which is not compatible with the GPL-3.0. Neither its code nor its data is used, and neither are the parts of PureMac derived from it.
- **MacOptimizer**: has no license, so nothing from it can be reused.
- **Atlas**: GPL-3.0, but its changes are too risky for a tool that promises undo.
- **Sparkle**: its debloat runs a script downloaded at run time, and it bundles `nvidiaProfileInspector.exe`. Neither is used.
- **LibreHardwareMonitor**: MPL-2.0 and a kernel driver. OmniGet reads sensors without a driver.
- **PresentMon API2 DLL**: not shipped. OmniGet runs the PresentMon command-line tool and reads its CSV.
- **winapp2.ini**, which BleachBit can import, is not included until its license is checked.
