# Third-party data, code and designs

OmniGet is GPL-3.0. This file lists what it takes from other projects, under which license, and where it lives in this repository. It starts with **washmybelly**, the cleanup, uninstall, privacy and performance superpower. The engines OmniGet runs for downloads (yt-dlp, FFmpeg, gallery-dl, aria2, librqbit and others) are credited in the README under "Standing on open source".

Every embedded source keeps its license file and a `SOURCE.md` with the upstream commit in `src-tauri/omniget-core/data/washmybelly/<source>/`. Nothing listed as data is downloaded at run time: it is compiled into the app with `include_str!`. Converted files are regenerated by the scripts in `scripts/washmybelly/`, never edited by hand.

### What did not go in, and why

- **Pearcleaner**: Apache-2.0 with the Commons Clause, which is not compatible with the GPL-3.0. Neither its code nor its data is used, and neither are the parts of PureMac derived from it.
- **MacOptimizer**: has no license, so nothing from it can be reused.
- **Atlas**: GPL-3.0, but its changes are too risky for a tool that promises undo.
- **Sparkle**: its debloat runs a script downloaded at run time, and it bundles `nvidiaProfileInspector.exe`. Neither is used.
- **LibreHardwareMonitor**: MPL-2.0 and a kernel driver. OmniGet reads sensors without a driver.
- **PresentMon API2 DLL**: not shipped. OmniGet runs the PresentMon command-line tool and reads its CSV.
- **winapp2.ini**, which BleachBit can import, is not included until its license is checked.
