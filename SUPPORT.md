# Getting help

| You want to | Go to |
|---|---|
| Learn how something works | [Docs](https://getomniget.com/docs/intro) and the [FAQ](https://getomniget.com/docs/faq) |
| Ask a question or share an idea | [Discussions](https://github.com/tonhowtf/omniget/discussions) or the [community chat](https://discord.gg/jgdxyPy7Vn) |
| Report a bug | [Open an issue](https://github.com/tonhowtf/omniget/issues/new/choose). The form asks for your version, system and the steps |
| Report a problem without a GitHub account | [getomniget.com/contact](https://getomniget.com/contact) |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) says. Never in a public issue |
| Ask for a site to be removed (platform owners) | [PLATFORM-OWNERS.md](PLATFORM-OWNERS.md) |
| Translate the interface | [Weblate](https://hosted.weblate.org/engage/omniget/) |
| Write code | [CONTRIBUTING.md](CONTRIBUTING.md) and [ARCHITECTURE.md](ARCHITECTURE.md) |

Before you open a bug report:

- Update to the latest version. Fixes only go into the latest release.
- If a download fails, open it in the queue and copy the diagnosis. It usually says whether the site changed, a login is missing or a tool needs an update.
- Search the open and closed issues for the error text.

OmniGet is maintained by one person. A clear report with steps is the fastest way to get a fix.
