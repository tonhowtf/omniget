# /music illustrations

Masters (transparent PNG) for the empty states and tools header of the
`/music` superpower, in the Loop sticker style of `assets/icons/menu/`.
The app ships 640 px WebP copies in `static/music/`; the menu icon master is
`assets/icons/menu/music.png` (32/64/128 px WebP in `static/icons/menu/`).

Generated with Higgsfield (Nano Banana Pro) using `league.png` and
`downloads.png` from `assets/icons/menu/` as style references, on a flat
magenta background that was then keyed out.
